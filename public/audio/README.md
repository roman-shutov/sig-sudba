# Фоновая музыка СИГ

Плейлист сайта состоит из двух треков:

1. `endless-bell-01.mp3`
2. `endless-bell-02.mp3`

Движок соединяет их в один аудиобуфер: первый играет до конца, затем второй,
после второго плейлист бесшовно начинается заново с первого.

Рекомендуемый мастер: бесшовный loop без тишины в начале и конце, одинаковые
гармония, ритм и атмосфера на границе, без fade-in и fade-out внутри файла.
Громкость и мягкое включение/выключение уже управляются интерфейсом сайта.
